The admin console is a React app (`apps/admin`, `make admin-dev`, [http://localhost:5273](http://localhost:5273)) that talks to the same API as everything else. It is how people review, correct, delete and explore. The screenshots below are the seeded Sarah workspace from `make demo-sarah`, in light and dark (your browser picks). Sign in with a key from `.local/dev-credentials.json` (for example `demo/admin@demo`); in production people sign in with single sign-on and API keys are break-glass.

## Roles decide what you see

A workspace admin sees everything; a **reviewer** sees reviews and evidence; an **operator** sees operations; agents and apps have no console. A different workspace's admin (`other_demo/admin@other`) sees none of this data, and the console says nothing about it.

## Retaking the screenshots

`apps/site/scripts/console-shots.mjs` retakes every screenshot against your own stack. It needs `make up seed`, a workspace from `make demo-sarah`, and `make admin-dev` running. Set `CHROMIUM_PATH` if Playwright's matching browser is not installed.
