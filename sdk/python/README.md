# kg-platform-sdk

A thin, typed Python client for the Knowledge & Memory Platform HTTP API. It does nothing the API does not: it forwards your key, retries safely, and raises typed errors.

```python
import os
from kg_platform_sdk import KGClient, NotFound, QuotaExceeded

async with KGClient(base_url=os.environ["KG_BASE_URL"], api_key=os.environ["KG_API_KEY"]) as kg:  # or KGClientSync
    ctx = await kg.build_context("Help Sarah assess starting a business", subject_ids=[sarah], profile="planning", max_tokens=600)
    prompt = f"<retrieved_context>\n{ctx.as_prompt_block()}\n</retrieved_context>\n\n{question}"  # quoted data, never instructions
```

## Methods
`build_context`, `ingest_interaction`, `get_interaction_status`, `propose_memory`, `save_working_memory`, `publish_memory`, `search_memory`, `get_evidence`, plus `list_profiles` and `usage`. Keyword arguments are the API's own fields (see `kg_platform_sdk.models`, generated from `contracts/openapi.json`). Every result has `.request_id`.

## Rules
- The key is an argument or `KG_API_KEY`; the base URL an argument or `KG_BASE_URL`. It is **never** logged and never in a `repr` or traceback.
- Every mutating call carries one `Idempotency-Key`, generated once and reused by its retries (pass `idempotency_key=` to choose it): the server sees one logical write.
- Retries (default 3) only for 429/502/503/504, honouring `retry_after` with jitter. A wait longer than `max_retry_wait` (30 s) is raised, not slept: a daily quota is `QuotaExceeded` with `retry_after`.
- Errors: `AuthError` (401, including a revoked key), `Forbidden`, `NotFound` (hidden = missing = foreign), `Conflict`, `ValidationError`, `InvalidEvidence`, `RuleViolation`, `RateLimited`, `QuotaExceeded`, `ContextIncomplete`, `ServerError`; all `KGError` with `code`, `status`, `request_id`, `details`, `retry_after`.
- Models are regenerated by `make sdk-models`; a test fails when `models.py` differs from a fresh generation.

The SDK imports nothing from the platform's own packages (import-linter), so it installs and runs anywhere that can reach the API. See [docs/agent-integration.md](../../docs/agent-integration.md).
